# ☕ Brew & Bean Coffee Shop UI

A modern, clean, and responsive coffee shop website with beautiful UI design and interactive features.

## 🎨 Features

### ✨ Modern Design
- **Clean & Minimalist**: Beautiful, modern interface with coffee-themed colors
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Smooth Animations**: Elegant transitions and hover effects
- **High-Quality Images**: Professional coffee shop photography from Unsplash

### 🛍️ Interactive Features
- **Shopping Cart**: Add items to cart with quantity controls
- **Menu Filtering**: Filter menu by categories (Coffee, Pastries, Sandwiches, Beverages)
- **Smooth Scrolling**: Navigate smoothly between sections
- **Mobile Menu**: Responsive navigation for mobile devices
- **Contact Form**: Working contact form with validation
- **Newsletter Signup**: Email subscription functionality

### 📱 Responsive Design
- **Mobile-First**: Optimized for mobile devices
- **Tablet Support**: Perfect layout for tablets
- **Desktop Enhanced**: Rich experience on desktop screens
- **Touch-Friendly**: Easy navigation on touch devices

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs locally

### Installation
1. **Download/Clone** the project files
2. **Open** `index.html` in your web browser
3. **Enjoy** the coffee shop experience!

### File Structure
```
Coffee Shop UI/
├── index.html          # Main HTML file
├── styles.css          # CSS styles and animations
├── script.js           # JavaScript functionality
└── README.md          # This documentation
```

## 🛠️ Customization

### 🎨 Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #8B4513;
    --secondary-color: #654321;
    --background-color: #f5f5f5;
    --text-color: #333;
}
```

### 🖼️ Images
Replace image URLs in `index.html`:
```html
<img src="your-image-url.jpg" alt="Description">
```

### 📝 Content
Update text content in `index.html`:
- Company name and description
- Menu items and prices
- Contact information
- About section content
